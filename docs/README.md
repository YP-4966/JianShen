# 健身房器械使用指南

> 面向健身房新手与进阶训练者的健身动作指南网页。按训练部位分类，每个动作配有 **GIF 动图演示**、详细步骤、注意事项与常见错误，帮助你安全、科学地安排每一次训练。

- 🔗 在线预览：<https://yp-4966.github.io/JianShen/>
- 📦 安卓安装包：`downloads/gymguide.apk`（由本仓库打包，与网页版本一致）
- 🏷️ 当前版本：**v25**

---

## ✨ 功能特点

| 功能 | 说明 |
|------|------|
| 9 大板块 · 65 个经典动作 | 热身、胸、肩、背、臀、腿、手臂、核心、有氧 |
| GIF 动图演示 | 每个动作配动态演示图，直观展示标准动作轨迹 |

| 搜索与筛选 | 按关键词搜索动作（中文名/英文名/训练部位），按器械、难度筛选 |
| 收藏功能 | ❤️ 一键收藏动作，集中复习（数据存于浏览器 localStorage） |
| 训练记录 | 📝 记录每次训练的动作、日期、组数、次数、重量，含统计（存于 localStorage） |

| 按部位规划训练 | 每个板块附「训练建议」（训练频率、动作顺序、组次安排） |

| 响应式布局 | 桌面 / 平板 / 手机自适应 |

## 🛠️ 技术栈

- **纯前端静态站**：原生 HTML + CSS + JavaScript，无框架、无构建工具
- **数据驱动渲染**：动作数据集中在 `js/data.js`，页面由 `js/main.js` 动态渲染
- **PWA 离线能力**：`manifest.webmanifest`（安装清单）+ `sw.js`（Service Worker）
  - 缓存名称 `jianshen-v2`，预缓存核心文件
  - 缓存策略：stale-while-revalidate（先返回缓存，后台更新）
- **Capacitor 打包 APK**：将网页封装为 Android 应用（离线可用、图标直达）
- **GitHub Pages 部署**：main 分支 / 根目录，推送后自动发布

## 📁 项目结构

```
/workspace
├── index.html              # 页面入口（引用资源带 ?v=25 版本参数）
├── css/
│   └── style.css           # 全局样式（CSS 变量主题、网格布局、吸顶导航、弹窗）
├── js/
│   ├── data.js             # 数据源：CATEGORIES(9 条) + EXERCISES(65 条)
│   └── main.js             # 渲染逻辑：分类/卡片/弹窗/搜索/筛选/收藏/记录/Tab
├── media/                  # 65 个动作 GIF 动图（来自 ExerciseDB）
├── icons/
│   ├── icon-192.png        # PWA 图标 192px
│   └── icon-512.png        # PWA 图标 512px（含 maskable）
├── manifest.webmanifest    # PWA 安装清单
├── sw.js                   # Service Worker（离线缓存）
├── downloads/
│   └── gymguide.apk        # Android 安装包（v25）
├── docs/
│   └── README.md           # 项目文档（本文件）
└── package.json            # 仅用于本地开发脚本的依赖（jsdom / puppeteer-core）
```

## 📝 数据格式说明

所有动作数据都在 `js/data.js` 的 `EXERCISES` 数组中，单个动作结构如下：

```js
{
  id: "barbell-bench-press",      // 唯一标识
  cat: "chest",                   // 所属板块（warmup/chest/shoulder/back/glute/leg/arm/core/cardio）
  name: "杠铃卧推",               // 中文名
  en: "Barbell Bench Press",      // 英文名
  gif: "media/EIeI8Vf.gif",       // 动图路径
  target: ["胸大肌", "肱三头肌"],  // 训练部位
  steps: ["..."],                 // 动作步骤
  tips: ["..."],                  // 注意事项
  mistakes: ["..."]               // 常见错误
}
```

**新增动作**：在 `js/data.js` 中追加对象，把 GIF 放入 `media/` 目录即可，页面会自动更新统计。

## 🚀 本地运行

无需安装任何依赖，任选一种方式：

```bash

python3 -m http.server 8000
# 访问 http://localhost:8000
```
