# 健身房器械使用指南

一个面向健身房新手与进阶训练者的健身动作指南网页，按训练部位分类，每个动作都配有 **GIF 动图演示**、详细步骤、注意事项与常见错误，帮助你安全、科学地安排每一次训练。

🔗 在线预览：<https://yp-4966.github.io/JianShen/>

## ✨ 功能特点

- **9 大板块 · 65 个经典动作**：热身、胸、肩、背、臀、腿、手臂、核心、有氧
- **每个动作配 GIF 动图演示**：直观展示标准动作轨迹
- **动作详情弹窗**：分步动作要领、注意事项（✓）、常见错误（✕）
- **按部位规划训练**：每个板块附「训练建议」（训练频率、动作顺序、组次安排）
- **一键跳转导航**：顶部导航与部位卡片均可点击定位到对应区域
- **完全离线可用**：所有图片素材内置在仓库中，纯静态页面，无需后端
- **响应式布局**：桌面 / 平板 / 手机自适应

## 🛠️ 技术栈

- **纯前端**：原生 HTML + CSS + JavaScript（无框架、无构建工具）
- 数据驱动渲染：动作数据集中在 `js/data.js`，页面由 `js/main.js` 动态渲染
- 图标与样式：CSS 变量主题、自适应网格布局、毛玻璃吸顶导航

## 🚀 本地运行

无需安装任何依赖，任选一种方式：

```bash
# 方式一：直接双击打开 index.html
# 方式二：本地静态服务器（推荐）
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 📝 自定义与扩展

所有动作数据都在 `js/data.js` 中，结构如下：

```js
{
  id: "barbell-bench-press",      // 唯一标识
  cat: "chest",                   // 所属板块（warmup/chest/shoulder/back/glute/leg/arm/core/cardio）
  name: "杠铃卧推",               // 中文名
  en: "Barbell Bench Press",      // 英文名
  gif: "media/EIeI8Vf.gif",       // 动图路径
  target: ["胸大肌", "肱三头肌"],  // 训练部位
  steps: ["..."],                 // 动作步骤
  tips: ["..."],                  // 注意事项
  mistakes: ["..."]               // 常见错误
}
```

新增动作：在 `js/data.js` 中追加对象，把 GIF 放入 `media/` 目录即可，页面会自动更新统计。
